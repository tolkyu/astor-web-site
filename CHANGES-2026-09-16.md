# Що змінено — 16 вересня 2026

До публікації входять редизайн `9887a0e` та налаштування розгортання з цього коміту.

## Сайт

- Оновлено головну сторінку, мобільний вигляд, навігацію, кнопки та типографіку.
- Додано видимі контакти, адресу, графік роботи та фото майстерні.
- Прайс має пошук, розгортання категорій і запис з обраною послугою.
- Форма запису працює також без JavaScript; помилки й результат показуються явно.
- Поліпшено клавіатурну навігацію, фокус і підтримку reduced-motion.

## Заявки, прайс і безпека

- Заявка зберігається до надсилання в Telegram; повтор запиту не створює дубліката.
- Невдалі доставки потрапляють у чергу; адміністратор може повторити надсилання.
- Адмінка показує заявки, редагує прайс і зберігає історію останніх 20 версій.
- Одночасне редагування цін виявляється як конфлікт.
- Сесія адміністратора використовує HttpOnly cookie; додано CSRF-захист і ліміт входів.
- Серверні файли, секрети й локальні дані не публікуються як статичні файли.
- Оновлено robots.txt, sitemap.xml, документацію та приклад змінних середовища.

## Vercel

- Статичні файли публікуються з `public/`, HTML та API обслуговує `api/index.js`.
- HTML-шаблони явно включені до serverless-функції.
- Явно вибрано Framework Preset `Other` і порожню команду збірки: сайт не потребує компіляції frontend; налаштування не залежать від автоматичного визначення Express чи старої Build Command у dashboard.
- Маршрути `/`, `/admin`, `/request` та `/api/*` спрямовані до Express.
- Щоденний повтор доставки о 07:00 UTC налаштовано у `vercel.json`.
- Для production потрібні Telegram token/chat id, `TELEGRAM_WEBHOOK_SECRET` і Redis REST URL/token. Для адмінки потрібен `ADMIN_PASSWORD_HASH`, для автоматичного повтору — `CRON_SECRET`.
- Значення секретів не включені до Git. Повний перелік налаштувань: `README-BACKEND.md`.
